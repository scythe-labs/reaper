# Refuted candidates — a grep index

A row here means a reviewer raised the candidate and an independent verifier **demonstrated the
trigger cannot occur**. Nothing softer qualifies: "declined", "unreachable today" and "not worth
acting on" are three other verdicts, and each of those goes to an issue instead.

**Query this file, do not read it.** Once you have a candidate, grep the path or symbol you are
about to report on:

```
grep -in 'season_pruning\|plan_series_prune' .claude/skills/reaper-review/references/refuted.md
```

A hit means read the row and either accept it or beat it. No hit means report.

**Every row is pinned to a commit.** If the cited code moved since, the refutation is stale and
the candidate is live again: re-derive rather than trusting either answer.

The two sections after the index are **not** refutations. Read their headings before using them.
