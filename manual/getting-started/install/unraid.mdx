# Unraid

Open the **Apps** tab, search for **Reaper**, and install it. Community Applications carries
the template.

Not in the search results yet? The same template lives in the repository. Copy
`contrib/unraid/my-Reaper.xml` to:

```
/boot/config/plugins/dockerMan/templates-user/
```

Then add the container from the template dropdown in the Docker tab.

## Ownership

The template ships **`PUID` `99`** and **`PGID` `100`**, so the appdata folder stays owned by
`nobody:users`, which is what the rest of Unraid expects. Keep them.

<Callout tone="note">
  The container starts as root only to take ownership of its data folder, then drops to that
  user before it opens the database. At the default the app runs as that user, not as root.
</Callout>

## Where the data goes

One path, Reaper's own database. The default in the template puts it under your appdata share.
Reaper needs no access to your media shares, so leave them unmapped.
